Instant Barcode

Gera e lê QR codes e códigos de barras

English

Escolhe o tipo de código, escreve o texto e o código aparece de imediato. Também podes ler um código existente com a câmara: a app identifica o tipo e preenche o texto por ti.

Perguntas frequentes

O código de barras não aceita o meu texto

O código de barras usa o formato Code 128, que só aceita caracteres sem acentos. Para texto com acentos, emojis ou várias linhas, usa o QR Code.

A leitura com a câmara não abre

O leitor é fornecido pelo Google Play Services. Confirma que está instalado e atualizado; na primeira utilização pode demorar uns segundos a descarregar.

A leitura mostra um ícone vermelho

O código foi lido, mas num formato que a app ainda não gera (por exemplo EAN-13), ou a leitura foi cancelada.

Onde ficam as imagens guardadas?

Na galeria, no álbum InstantBarcode (pasta Imagens/InstantBarcode). Para partilhar, usa o botão Partilhar e escolhe a app.

Instant Barcode (English)

Pick a code type, type your text and the code appears instantly. You can also scan an existing code with the camera; the app detects its type and fills in the text.

The barcode option uses Code 128, which only accepts unaccented characters; use QR Code for anything else. Scanning is provided by Google Play Services, which must be installed.
